# 🤖 What Can I Do? - AI Coding Assistant Capabilities

## Overview

As an advanced AI coding assistant, I'm designed to help developers with a wide range of software development tasks. Here's a comprehensive guide to my capabilities:

- **Code Refactoring**: Improve existing code structure, readability, and performance

## 🚀 What I Can't Do

It's important to understand my limitations:

- **No Direct GitHub Operations**: I can't directly push to GitHub, create PRs, or update issues without using provided tools
- **No Internet Access**: Limited access to external resources (many domains are blocked)
- **No Real-Time Execution**: I work in a sandboxed environment
- **No Access to Secrets**: I can't access your passwords, tokens, or sensitive credentials
- **No Force Push**: Can't rewrite Git history or force push changes

## 💡 How to Work With Me

### Best Practices
1. **Be Specific**: Clear, detailed requests get better results
2. **Provide Context**: Share relevant code, error messages, and requirements
3. **Iterative Approach**: I work best with step-by-step refinements
4. **Validation**: I'll test and validate changes before finalizing
5. **Security First**: I prioritize security and best practices
